# My Portfolio

A personal developer portfolio website showcasing projects, skills, and contact information.

## Overview

This is my personal portfolio built with React and Vite, featuring smooth animations, interactive elements, and a clean dark-themed design. It highlights selected projects across web development, mobile, and AI, with sections for skills, education, and a contact form.

## Features

- **Animated Hero Section**: Mouse-parallax effect and smooth entrance animations.
- **Projects Showcase**: Highlighted projects with tags, descriptions, and links.
- **Skills Overview**: Visual breakdown of technologies and tools.
- **Scroll Progress Bar**: Tracks reading progress across the page.
- **Contact Integration**: Email shortcut with Gmail deep-link support.
- **Framer Motion Animations**: Page transitions and reveal animations throughout.

## Tech Stack

- **Framework**: React 19, Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- npm

### Installation

```bash
git clone https://github.com/danyl-dnl/my-portfolio.git
cd my-portfolio
npm install
```

## Running Locally

```bash
npm run dev
```

The site will be available at `http://localhost:5173`.

## Project Structure

- `src/App.jsx`: Main application component containing all sections and logic.
- `src/assets/`: Static assets such as images used in the portfolio.
- `public/`: Publicly served files.
